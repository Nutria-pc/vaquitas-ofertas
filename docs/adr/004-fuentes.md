# ADR-004 · Fuentes y scraping responsable
- Fecha: completar por el equipo
- Contexto: mínimo de 4 tiendas, al menos 2 HTML, más 3 fuentes HTML totales.
- Alternativas: tiendas de plataforma admitidas y minoristas admitidos; API oficial sustituta documentada.
- Decisión: pendiente de auditar robots.txt, términos, tasa y disponibilidad regional.
- Consecuencias: mantener evidencia de selectores y fecha de verificación; no evadir bloqueos.
- Estado: propuesta.
