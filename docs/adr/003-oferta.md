# ADR-003 · Definición de oferta
- Fecha: completar por el equipo
- Contexto: una tienda puede mostrar precio regular tachado; el catálogo también puede tener MSRP.
- Alternativas: precio menor al MSRP; precio menor al precio regular; criterio combinado.
- Decisión: pendiente. No marcar ofertas hasta aprobar este criterio.
- Consecuencias: afecta porcentaje de descuento y etiqueta de oferta.
- Estado: propuesta.
